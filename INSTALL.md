# РукUP — как запустить

Платформа занятий школьников с репетиторами по принципу поднятой руки. Это сайт: сервер запускается на компьютере, а открывается в браузере на компьютере и телефоне.

## Что нужно

- Node.js версии 22.13 или новее: https://nodejs.org/ (кнопка LTS).
- Интернет нужен только для двух вещей: запуск Python в разделе «Дисциплины» и вкладка «Сайты».

## Запуск

1. Распакуйте архив в любую папку.
2. Откройте в этой папке терминал (в Windows: Shift + правая кнопка мыши → «Открыть окно PowerShell здесь»).
3. Выполните команду:

   ```
   node server.js
   ```

4. Откройте в браузере адрес http://localhost:3000

Если раньше запускалась старая версия («Репетитор»), сначала остановите её: в её окне терминала нажмите Ctrl + C. Иначе адрес будет занят и откроется старый сайт.

## Админы

При первом запуске сервер создаёт двух админов, `admin1` и `admin2`, со случайными паролями. Пароли печатаются в терминале и сохраняются в файл `data/admins.txt`. Запишите их и удалите файл.

Новые пароли админов: `node server.js --reset-admins`

Админ видит фиолетовую вкладку «Открытый код»: список пользователей (смена класса, сброс пароля, блокировка, удаление) и исходный код.

## Как проверить вдвоём на одном компьютере

1. В обычном окне браузера зарегистрируйте ученика (класс 10).
2. В окне инкогнито зарегистрируйте репетитора (предмет «Математика»).
3. У ученика нажмите «Поднять руку», выберите «Математика».
4. У репетитора слева появится рука: нажмите на неё и пригласите ученика.
5. Ученик принимает приглашение — начинается занятие с общей доской и общим кодом.

## Телефон в той же сети Wi-Fi

Узнайте адрес компьютера в сети (в Windows команда `ipconfig`, строка «IPv4-адрес») и откройте на телефоне `http://адрес:3000`.
Звонок с телефона по такому адресу работать не будет: браузеры дают доступ к микрофону только на `localhost` или по `https`. Всё остальное (рука, чат, практика, дисциплины) работает.

## Проверка

```
node test/run.js
```

Автотесты запускают сервер на временной базе и проверяют правила, занятия, оплату, практику и защиту.

## Настройки (переменные окружения)

| Переменная | Что делает |
|---|---|
| `PORT` | порт, по умолчанию 3000 |
| `DATA_DIR` | папка с базой данных, по умолчанию `data` |
| `PUBLIC=1` | режим размещения в интернете за обратным прокси (https) |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | свой TURN-сервер для звонков через сложные сети |

## Что важно знать

- Кошелёк учебный: настоящие деньги не списываются.
- Ответы к работам раздела «Практика» лежат в папке `works`. Их нужно проверить перед использованием.
- База данных — файл `data/rukup.db`. Чтобы начать с нуля, остановите сервер и удалите папку `data`.

## Сайт в интернете (Render)

Платформа размещена на бесплатном тарифе хостинга Render и берёт код из этого репозитория: после каждого изменения на GitHub сайт обновляется сам.

Настройки сервиса на Render:

| Поле | Значение |
|---|---|
| Build Command | `npm install` |
| Start Command | `node server.js` |
| `NODE_VERSION` | `22` |
| `PUBLIC` | `1` |
| `ADMIN1_PASSWORD`, `ADMIN2_PASSWORD` | пароли админов (не короче 8 символов) |

Ограничения бесплатного тарифа:
- если на сайт 15 минут никто не заходил, он засыпает, и первое открытие занимает около минуты;
- база данных хранится в файле, который стирается при каждом перезапуске и обновлении сервиса: аккаунты, рейтинги и сообщения пропадают. Админы появляются снова с паролями из настроек.
